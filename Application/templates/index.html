About the project

Researching clearer traffic-sign awareness for Malaysian roads.

TSDR System is a final-year project that combines OpenCV image enhancement, YOLO object detection and YOLO-based image classification into one practical traffic sign detection and recognition workflow.

What happens to an image?

  1. EnhanceOpenCV applies CLAHE and/or gamma correction to improve sign visibility.
  2. LocateA YOLO detector proposes traffic-sign regions.
  3. GuardGeometry and face checks reject likely false positives.
  4. RecogniseThe YOLO classification model recognises the cropped signs and maps them to readable names.
  5. RecordAccepted observations are saved for review.
